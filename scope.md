# Scope of Assessment

## Authorized Target

- Application: OWASP Juice Shop
- Target URL: `http://127.0.0.1:3000`
- Hosting environment: Local Docker container running on my own Kali Linux virtual machine

## Purpose

This assessment is performed only for cybersecurity learning and portfolio development. OWASP Juice Shop is an intentionally vulnerable application designed for security training.

## Allowed Activities

- Browser-based exploration of the local application
- Intercepting and reviewing local HTTP requests with Burp Suite
- Testing selected vulnerabilities within the self-hosted Juice Shop lab
- Recording evidence, impact, and remediation recommendations

## Out of Scope

- Any public website, external IP address, college/work network, or third-party system
- Denial-of-service testing
- Testing against systems without explicit authorization

## Assessment Focus

- Web application security fundamentals
- Request interception and analysis using Burp Suite
- Authentication and input-validation issues
- VAPT reporting and remediation documentation
